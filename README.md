# TERRA INCOGNITA

Образовательная браузерная игра по географии для школьников 5–11 классов. Вы — руководитель экспедиции на неизвестной планете X-01: исследуете территории, решаете задачи о рельефе, климате и водах, открываете новые районы и ведёте журнал экспедиции.

Чистые HTML, CSS и JavaScript, без сборки, серверной части и внешних зависимостей. Прогресс хранится в `localStorage`.

## Запуск

- **GitHub Pages** (основной способ): см. ниже.
- **Локально:** в папке проекта выполните `python3 -m http.server 8000` и откройте `http://localhost:8000/`.
- **Двойной клик по `index.html`** тоже работает: при недоступном `fetch` игра берёт данные из `scripts/data-bundle.js` (копия `data/*.json`).

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите в него все файлы проекта.
2. *Settings → Pages → Build and deployment*: Source — **Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет доступен по адресу `https://<username>.github.io/<repository>/`.

Все пути относительные, поэтому игра работает и в корне домена, и в подпапке репозитория.

## Структура

```
index.html            страница
styles/main.css       оформление
scripts/              storage.js (сохранения) · game.js (логика) · map.js (SVG-карта)
                      tasks.js (задания) · ui.js (окна, звук) · app.js (экраны)
                      data-bundle.js (автокопия данных для запуска с диска)
data/                 world.json · sectors.json · tasks.json · discoveries.json · events.json
tools/                сборка данных и сквозной тест (не нужны для работы игры)
```

## Как устроена игра

- 12 секторов, у каждого 3 обязательных и 1 дополнительное задание (всего 48). Дополнительное открывается после исследования сектора.
- Статусы: не обнаружена → обнаружена → исследуется → исследована → полностью изучена. Различаются цветом, контуром, штриховкой и значком.
- Новый сектор открывается, когда исследованы все сектора из его списка `requires`. Граф: старт → Горный барьер и Речная долина → Теневая равнина, Лесной склон, Внутренняя котловина (нужны оба: Горный барьер и Речная долина), Дельта; далее Пустыня, Полярная область, Вулканическое нагорье, Тёплое течение → Остров Дальний.
- Типы заданий: вопрос с вариантами, определение объекта, анализ, выбор области на схеме. Ошибки не штрафуются: игра показывает правильный ответ и объяснение, можно повторить. Подсказка есть в каждом задании.
- Очки: 100 обычное, 150 комплексное, 50 дополнительное. 7 достижений. Журнал хранит 30 последних событий.

## Сохранение

Ключ `terraIncognitaSave`, формат версии 1. В настройках: экспорт в `terra-incognita-save-ГГГГ-ММ-ДД.json`, импорт с проверкой структуры, версии и идентификаторов, сброс с подтверждением. Повреждённое сохранение не ломает игру: предлагается начать заново или импортировать копию.

## Добавление контента

Секторы, задания и открытия лежат в `data/*.json`; движок менять не нужно. При запуске данные проверяются (уникальность id, ссылки, ответы, подсказки, достижимость секторов), ошибки выводятся в консоль. Задания проще править в `tools/tasks_*.py` и собрать командой:

```
python3 tools/gen_tasks.py && python3 tools/build_bundle.py
```

## Проверка

`python3 tools/e2e_test.py` (нужны Python и Playwright) проходит игру до конца через интерфейс и проверяет очки, достижения, перезагрузку, экспорт, импорт (в том числе плохие файлы), сброс и узкий экран 360 px.

## Известные ограничения

- На экране уже 600 px карта прокручивается внутри своей рамки (подписи остаются читаемыми).
- Карта схематична; масштабирование и перетаскивание не реализованы (в ТЗ необязательны).
- Звук — простые сигналы WebAudio, по умолчанию выключен.
- Прогресс привязан к браузеру; перенос между устройствами — через экспорт/импорт.
